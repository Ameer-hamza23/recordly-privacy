# Narration provenance

The owner approved using a free commercial-use voice instead of ElevenLabs Free on 16 October 2026.

English explanatory narration was generated locally with Kokoro v1.0, voice `af_heart`. Model weights are Apache-2.0: https://huggingface.co/hexgrad/Kokoro-82M . The kokoro-onnx runtime is MIT: https://github.com/thewh1teagle/kokoro-onnx . This package contains generated output, not model weights or runtime code. Exact local model/voice-data hashes and runtime version are recorded in `voice-generation.json`.

No original personal recording was sent to a voice service. A brief genuine microphone test remains pitch altered and explicitly labeled in the video. Synthetic explanatory narration is not evidence that those words were captured from the microphone. The facecam character is an editing overlay, not an app feature. No ElevenLabs audio was generated or included.
