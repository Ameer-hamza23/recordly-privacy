# Recordly recording demonstration

Privacy revision 2 uses an opaque illustrated character over the complete camera area, including its moving opening. The character is a privacy edit, not an in-app camera feature. Every required camera-cover frame passed pixel checks; the 52-second video contains 1,560 frames. Natural English narration is generated locally using Kokoro v1.0, voice af_heart (Apache-2.0 model, MIT runtime). See VOICE-LICENSE.md. Narration is explanatory; a brief voice-altered original microphone test remains labeled.

The player uses the versioned MP4 to avoid older browser caches. The older direct MP4 URL serves the same safe file. Earlier versions of that unversioned MP4 were removed from reachable repository history with owner approval on 16 October 2026. Do not merge old website clones back into this repository; re-clone it. GitHub caches or external copies are outside this history rewrite.

Raw personal video and intermediate original audio must never be committed or published. No ElevenLabs audio is included. The owner approved the free commercial-use Kokoro alternative.
