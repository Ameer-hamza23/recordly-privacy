# Recordly privacy and support

Public privacy policy for Recordly: Screen Recorder by Zenith Stack Studio.

- Website: https://ameer-hamza23.github.io/recordly-privacy/
- Support: zenith.stack.studio@gmail.com
- App package: com.recordly.screenrecorder

This repository contains only the public website. The Android app source belongs in the separate private Recordly repository.

## Edit and publish

Edit `index.html` and commit to `main`. GitHub Pages publishes from `main` / root. No build dependencies are needed.

The domain-root `app-ads.txt` used by AdMob is maintained in the `ameer-hamza23.github.io` repository. A copy is included here for reference; AdMob does not discover it at this project subpath.
